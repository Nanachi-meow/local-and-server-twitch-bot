# Спецификация тем чат-виджета (для ИИ и ручного редактирования)

Формат описывает **дизайн чат-виджета** бота (страница `/chat`, панель → Оверлеи →
«💬 Чат-виджет» → «🎨 Конструктор дизайна»). Файл темы — обычный JSON. Его можно
**импортировать** кнопкой «⬆ Импорт» в конструкторе (затем «💾 Сохранить») — и дизайн
применится к странице `/chat`. Экспорт кнопкой «⬇ Экспорт» выдаёт файл ровно этого формата.

## Какую задачу решает формат

Чат-виджет рендерит колонку сообщений: **чип юзера** (цветной прямоугольник с ником)
и под ним **бабл сообщения** (плашка с текстом). Всё оформление сводится к параметрам
ниже — своего CSS тема не несет, произвольный код не исполняется. Это осознанный
компромисс: любая тема гарантированно безопасна и совместима с импортом.

## Структура файла

```json
{
  "format": "twitch-bot-chat-theme",
  "version": 1,
  "theme": { "…": "…см. поля ниже…" }
}
```

- `format` и `version` — необязательные метки (импортер понимает и «голый» объект `theme`).
- `theme` — единственное содержательное поле; все поля темы необязательны: пропущенное
  берётся из значений по умолчанию, неверное — заменяется дефолтом (санитизация на сервере).

## Поля темы

| Поле | Тип | Диапазон | По умолчанию | Что делает |
|---|---|---|---|---|
| `name` | строка | ≤40 симв. | `чистая` | Название (показывается только в панели) |
| `x` | число | 0–1600 | 40 | Отступ колонки от левого края сцены, px (сцена 1920×1080) |
| `y` | число | 0–1000 | 40 | Отступ колонки от низа сцены, px |
| `maxWidth` | число | 20–100 | 80 | Максимальная ширина колонки, % ширины сцены |
| `gap` | число | 0–120 | 24 | Вертикальный промежуток между сообщениями, px |
| `scale` | число | 25–300 | 100 | Масштаб всего виджета, % |
| `fontFamily` | строка | ≤80 симв. | `""` | CSS font-family (пусто = шрифт страницы) |
| `fontSize` | число | 10–60 | 16 | Размер текста сообщения, px (размер ника = ему же) |
| `chipBg` | цвет | hex | `#a6a9d3` | Фон чипа обычного зрителя и саба |
| `chipColor` | цвет | hex | `#f0e7e5` | Цвет текста ника |
| `chipRadius` | число | 0–60 | 20 | Скругление углов чипа, px |
| `chipCase` | bool | — | true | Ник в верхнем регистре |
| `gem` | bool | — | false | Ромб-декор слева от чипа (цвет чипа) |
| `msgBg` | цвет | hex | `#141520` | Фон бабла сообщения |
| `msgColor` | цвет | hex | `#a6a9d3` | Цвет текста сообщения |
| `msgBorder` | цвет | hex | `#6a6d98` | Цвет рамки бабла |
| `msgBorderWidth` | число | 0–12 | 2 | Толщина рамки бабла, px (0 = нет) |
| `msgRadius` | число | 0–60 | 15 | Скругление углов бабла, px |
| `msgPaper` | bool | — | false | Эффект «сложенной бумаги»: повёрнутый слой позади бабла |
| `colorBroadcaster` | цвет | hex | `#f1592a` | Чип стримера |
| `colorModerator` | цвет | hex | `#edb872` | Чип модератора |
| `colorVip` | цвет | hex | `#a672ed` | Чип VIP |
| `ghost` | bool | — | false | Призрак, парящий над чипом сабскрайбера |
| `webs` | bool | — | false | Паутинка в углу бабла |
| `subStar` | bool | — | true | Звёздочка саба на чипе |
| `animIn` | строка | `scale` \| `slide` \| `fade` | `scale` | Анимация появления сообщения |

Цвета — строки `#rrggbb` (можно `#rgb`, `#rrggbbaa`). Лимиты жёсткие: числа вне
диапазона зажимаются, не-цвет заменяется дефолтом — кривой файл не сломает виджет.

## Правила генерации тем (для ИИ)

1. Соблюдай только поля таблицы. Никаких CSS-строк, url(), инъекций HTML/JS —
   такие значения будут выброшены санитизацией.
2. Все поля необязательны: генерируй минимум, остальное дорисует дефолт.
3. Думай контрастом: `chipColor` читается на фоне `chipBg`; `msgColor` — на `msgBg`.
   Цвета ролей должны отличаться друг от друга и от `chipBg`.
4. Декор (`gem`, `ghost`, `webs`, `msgPaper`) — выключен по умолчанию: это украшения
   для тематических чатов, не база. Включай осознанно (например, «хэллоуин»-тема).
5. Одна тема = одна идея (минимализм, неон, стекло…). Сначала выбери 4–6 ключевых
   цветов и радиусы, потом раскидай по полям.
6. Файл валиден, если `JSON.parse` проходит и в `theme` лежит объект.

## Примеры

### Минимализм (почти дефолт, тёплые тона)

```json
{
  "format": "twitch-bot-chat-theme",
  "version": 1,
  "theme": {
    "name": "тёплый минимализм",
    "chipBg": "#8a817c",
    "chipColor": "#fffaf5",
    "msgBg": "#1c1917",
    "msgColor": "#f5f0ea",
    "msgBorder": "#3d3733",
    "msgBorderWidth": 1,
    "msgRadius": 10,
    "chipRadius": 10,
    "animIn": "slide"
  }
}
```

### Хэллоуин (как собрать декоративную тему)

```json
{
  "format": "twitch-bot-chat-theme",
  "version": 1,
  "theme": {
    "name": "хэллоуин",
    "chipBg": "#a6a9d3",
    "msgBg": "#141520",
    "msgBorder": "#6a6d98",
    "msgPaper": true,
    "gem": true,
    "ghost": true,
    "webs": true,
    "colorBroadcaster": "#f1592a",
    "colorVip": "#a672ed",
    "animIn": "scale"
  }
}
```

### Неон

```json
{
  "format": "twitch-bot-chat-theme",
  "version": 1,
  "theme": {
    "name": "неон",
    "chipBg": "#0f0326",
    "chipColor": "#00f0ff",
    "chipRadius": 4,
    "msgBg": "#0b0121",
    "msgColor": "#e6faff",
    "msgBorder": "#00f0ff",
    "msgBorderWidth": 2,
    "msgRadius": 6,
    "colorBroadcaster": "#ff2b6d",
    "colorModerator": "#ffb300",
    "colorVip": "#b026ff",
    "animIn": "fade",
    "fontFamily": "Consolas, monospace"
  }
}
```

## Как импортировать

1. Панель → Оверлеи → «💬 Чат-виджет» → «🎨 Конструктор дизайна» → «⬆ Импорт».
2. Выбрать файл темы (`.json`) — поля конструктора заполнятся, превью перерисуется.
3. Нажать «💾 Сохранить» — тема уедет на сервер и мгновенно применится к странице `/chat`.
