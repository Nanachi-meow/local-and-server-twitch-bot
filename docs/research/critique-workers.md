## Дыры в тестах строителей (кейсы, которые selftest НЕ покрывает)

1. **Авто-возврат по таймауту не протестирован** (worker-a): тестируется только ручной `closeExpired(...)` с ручным `pts2.add` (selftest:777–779) — путь `_tick → _give → points.add`, обещанный README («бот сам закрывает и возвращает»), и возвраты при `bets.stop()` (selftest:786 проверяет только `bets._timer === null`) не покрыты. Ровно там мог бы прятаться баг типа «points не подключён → возвраты в никуда».
2. **`place` после экспирации** (`время ставки уже вышло`, bets.js:111) — guard есть, теста нет.
3. **`challenge` на несуществующий ник** — не тестируется (и не валидируется — см. дефект №2).
4. **Кулдаун у ПРИНЯВШЕГО** — `accept()` пишет `_duelLast` для принимающего (bets.js:286) — поведение никем не проверено и нигде не описано; возможно, это не то, что задумывалось (принявший «сжигает» свой кулдаун).
5. **Дробные `optionIndex`/`winnerIndex`** — см. дефект №6, тестов нет.
6. **Клиентский TTS не тестируется вообще** (worker-c): `fillTtsVoices`/`collectAlerts`/`speak`/`pickVoice` — чистые функции-HTML-генераторы можно было бы вынести и покрыть; именно поэтому дефекты №1 (voiceName-вайп) и №9 прошли мимо 187 зелёных тестов. Минимум — вынести генератор `<option>`-списка в чистую функцию и протестировать случай «список пуст + есть сохранённое имя».
7. **Двойная отправка одного сообщения** (дедуп по message_id) — см. дефект №11 — не тестируется нигде.

## Проверено и чисто (ответы на вопросы ТЗ)

- **Race между closeExpired и resolve — нет.** Оба пути синхронны (Node, один поток; между `place`/`resolve` и payout нет `await`), оба **удаляют пул до** выплат/возвратов → двойной выплаты «итог + таймаут» физически не может быть. Протухший-но-не-протикавший пул безопасно резолвится модом; `!ставить` отсекается собственной проверкой экспирации (bets.js:111).
- **Делёж банка сходится точно.** `Σвыплат == prizePool` всегда: floor-доли + остаток `rest` раздаётся по +1 сверху-вниз по ставке (bets.js:180–185). Ручная проверка: pot=100, fee=10 → prizePool=90, доли 1/1/2 → 22+22+45=89, rest=1 → большему → 23+22+45=90 ✓. «Теряются» только fee (by design) и сгоревший банк (дефект №3).
- **Двойной вызов одного юзера в тотализаторе** — корректен: несколько записей `bets` на один вариант разрешены, `byLogin` суммирует ставки (bets.js:166–171); повторный `accept`/второй итог дают внятные ошибки; повторный `challenge` от того же лица блокируется «waiting».
- **Дуэльные деньги сходятся во всех путях:** challenge→spend→(fail: cancel+not-charged), accept→spend→(fail: refund from), win→+2N, timeout→refund from, stop()→refund всех. Проверил каждую ветку в commands.js:696–729.
- **Quotes: конкурентные add/remove** — id-коллизий нет: `_nextId++` синхронен в одном потоке, «fast-двойной клик» = два сообщения = две записи ( дубль-контент — см. дефект №11, дедупа нет); отсутствие `data/quotes.json` — ок (`loadJson([])` → пустое хранилище, покрыто тестом `quotes-empty.json`); XSS негде: роутов quotes в `server.js` нет, текст цитат уходит только в чат как plain text.
- **TTS-батарея OBS/старый CEF — не упадёт:** feature-detect `'speechSynthesis' in window`, `addEventListener?.()`, `try/catch` вокруг конструктора и `speak()` (overlay.html:81–106). Худший случай — тихое молчание (голоса в CEF могут отсутствовать, особенно Linux-сборки OBS без TTS-модуля); но диагностики в оверлее нет — только `#conn` про SSE. Рекомендация: тихий индикатор «TTS: нет голосов» рядом с `#conn`.
- **Лукап voiceName при несоответствии** — fallback есть и в оверлее, и в тест-кнопке панели (точное имя → первый `^ru` → null → дефолт), документирован в подсказке панели. Дыра только в сохранении — дефект №1.
- **Сбор alerts+tts в PUT** — да: `collectAlerts()` включает и 5 kind-строк, и `tts`; обе кнопки (`ov-save`, `tts-save`) шлют один и тот же полный объект; сервер мержит поэл field (index.js:321–338, `normalizeTts(cur+patch)`), поля meme/wheel не затираются. Найденные дыры — №1 и №9.
- **Швы мерджа:** маркеров `<<<<<<<`/`=======`/`>>>>>>>` в дереве нет (grep чисто); `RESERVED` пополнен (`цитата`, `ставка`, `ставить`, `итог`, `дуэль`) — захват имён через `!addcmd` невозможен; shutdown-порядок **корректен**: `bets.stop()` (L605) → `points.stop()` (L606) — возвраты экспирации попадают в store до `points.saveNow()`, `quotes.stop()` независим; wiring полный (`setBets`/`setQuotes`/`setPoints`/`bets.start()`).
- **README/ROADMAP синхронизированы** с новым поведением (разделы «Цитаты», «Ставки и дуэли», TTS-шаг в оверлее, `bets.*` в настройках) — расхождений с фактическим API команд не нашёл; ROADMAP честно оставил «Панель: быстрые кнопки ставок/цитат» незакрытыми.
