# 🎵 Полный шаблон плеера — СО ВСЕМ функционалом

Готовая страница плеера музыки со **всем**, что умеет бот. Не подключена к боту —
лежит тут как заготовка. Когда захочешь использовать:

1. Сохрани свои текущие `player/index.html` (если правила).
2. Скопируй этот файл в `player/index.html`.
3. Готово — страница `/music` сразу подхватится ботом, обновлять ничего не надо.

## Что внутри (всё, что даёт контракт бота)

| Функция | Как работает |
|---|---|
| Проигрывание YouTube | IFrame API, честный звук в OBS (отдельная аудиодорожка) |
| Сейчас играет | бегущая строка по твоему шаблону `{title} {by} {author} {duration}` |
| Очередь | список следующих треков: название + кто заказал + время |
| Тест плеера | события `srtest` — трек играет «мимо очереди», плашка «🧪 Тест» |
| Управление | ⏭ скип, ⏸/▶ паза, 🔇 мут, ползунок громкости — прямо в плеере |
| Конец трека | сам сообщает боту (`op:'ended'`) → очередь продвигается |
| Пауза из чата/панели | SSE-события `pause`/`resume`/`stop` — кнопки переворачиваются |
| Простой | ничего не играет → плеер гаснет (по желанию — `hideOnIdle`) |

## Как кастомизировать

Всё в одном файле, конфиг — вверху, в объекте `CFG`:

```js
const CFG = {
  W: 600, H: 340,        // размер плеера, px
  accent: '#8b5cf6',     // акцентный цвет
  bg: '#0c0a19',        // фон подложки
  bgOpacity: 0.8,       // прозрачность подложки (0-1)
  queueCount: 5,         // сколько треков показывать в очереди (0 = скрыть очередь)
  showControls: true,   // панель управления (для ручного режима; в OBS можно скрыть)
  hideOnIdle: true,     // прятать плеер, когда ничего не играет
};
```

Дальше — HTML/CSS/JS правь как угодно: контракт с ботом — только
`GET /api/songs`, SSE `/overlay/feed`, `POST /api/songs {op:'ended'}`,
`POST /api/actions/srnext` / `srcontrol`, `PUT /api/settings` (громкость).
