## Команды

### Встроенные

Каждую можно **выключить** в панели: Команды → подвкладка «🔧 Встроенные» (галочка). Выключенная команда перестаёт отвечать в чате, но имя остаётся за ней зарезервированным.

**Доступ** у встроенных и кастомных настраивается набором ролей: ткни кнопку в колонке «Доступ» → галочки (все / сабы / випы / моды). Выбранные роли — строгий список («випы и моды» = саб и обычный зритель не могут). Пусто — действует уровень по умолчанию («моды+» = моды и выше). Владелец канала может всегда.

| Команда | Доступ | Что делает |
|---|---|---|
| `!commands` / `!help` | все | список команд |
| `!uptime` | все | сколько стрим идёт |
| `!game`, `!title` | все | категория и название стрима |
| `!followage [ник]` | все | сколько человек фолловит канал |
| `!so <ник>` | мод+ | настоящий шатаут Twitch + строка-приветствие |
| `!pin <текст>` | мод+ | закрепить текст в чате на 20 минут |
| `!unpin` | мод+ | снять закреп |
| `!announce [цвет] <текст>` | мод+ | цветное анонс-сообщение (цвет: blue/green/orange/purple/primary) |
| `!addcmd !имя <ответ>` | мод+ | добавить команду |
| `!editcmd !имя <ответ>` | мод+ | изменить ответ команды |
| `!delcmd !имя` | мод+ | удалить команду |
| `!цитата` | все | случайная цитата |
| `!цитата N` | все | цитата по номеру |
| `!цитата поиск <текст>` | все | поиск по цитатам |
| `!цитата добавить <текст>` | мод+ | сохранить цитату |
| `!цитата удалить N` | мод+ | удалить цитату |
| `!ср <ссылка>` | все | заказать песню (YouTube) |
| `!ср` | все | что сейчас играет |
| `!очередь` | все | очередь музыки |
| `!скип` | мод+ | пропустить трек |
| `!музыка пауза\|прод\|стоп` | мод+ | управление музыкой |
| `!колесо` | все | рулетка-случайность (бесплатная) |
| `!мем [название]` | все | показать мем-алерт в оверлее |
| `!сказать <текст>` | все | озвучить фразу через TTS |
| `!сцена <имя>` | мод+ | переключить сцену OBS |
| `!сцены` | мод+ | список сцен OBS |
| `!bot` | все | кто я такая |

### Кастомные и фан-команды

Создаются из панели (вкладка «Команды», подвкладка «🧩 Кастомные») или чатом (`!addcmd`). Режимы ответа:

- **один ответ** — фиксированный текст-шаблон
- **несколько вариантов** — список по строке, бот тянет случайный
- **рандом-число** — бросает число в диапазоне, отвечает по диапазонам (например: 1-10 = «почти не хорни», 90-99 = «срочно остудитесь», 100 = «слишком хорни»)

Переменные: `{user}` `{target}` `{args}` `{channel}` `{uptime}` `{game}` `{title}` `{random:1-100}` `{roll}`

## Каналы

До 10 каналов. Добавление/удаление на ходу из панели. В каждом канале, где нужны шатауты/анонсы/закрепы, бот должен быть модератором.

## События и шаблоны

На каждое Twitch-событие — свой шаблон и режим (текст или анонс):
- Новый фоллоу (`!followage` тоже здесь)
- Рейд (сколько зрителей)
- Саб / продление / продление / подаренная подписка
- Стрим онлайн / оффлайн

Переменные: `{user}` `{viewers}` `{months}` `{recipient}` `{channel}`

## Таймеры

Периодические сообщения по расписанию. У каждого: интервал (в минутах), условие («по времени» / «по сообщениям» / «и» / «или»), вкл/выкл.

Режимы: «по времени» (раз в N минут), «по сообщениям» (после N сообщений в чате), «и время, и сообщения» (оба условия), «или время, или сообщения» (любое из них).

## Музыка

Зрители заказывают треки через `!ср <ссылка YouTube>`. Бесплатные команды — оплата через **награды канала Twitch** (см. ниже) или просто так.

- Плеер: отдельная страница **`http://localhost:8080/music`** (Browser Source в OBS) — видео, бегущая строка «сейчас играет» (кто заказал и что), тумблер вкл/выкл в правом верхнем углу
- Отдельная аудиодорожка: правый клик по источнику в микшере OBS → «Расширенные свойства аудио» → назначь дорожку, отличную от стрима
- Кастомизация: папка **`player/`** — вся страница плеера одним файлом `index.html` (цвета/размеры/скорость строки — переменные в шапке). Не нравится — клади свой, контракт описан в `player/README.md`
- Шаблон «сейчас играет»: панель → 🎵 Музыка → поле (переменные `{title}`, `{by}`, `{author}`, `{duration}`)
- Фильтры и правила: макс. длительность, суммарная длина треков юзера, мин. просмотры, кулдаун на юзера, чёрный список треков, кто может заказывать (роли/фолловеры/личный список)
- Заказы: командой `!ср` или наградой канала (название настраивается; при отказе баллы возвращаются)

## Награды канала

Channel Points — встроенная валюта Twitch. Зрители покупают награды, бот видит событие и реагирует.

**Как включить:**
1. В dev.twitch.tv/console → твоё приложение → добавь ВТОРОЙ Redirect URL: `http://localhost:8080/auth/broadcaster/callback`
2. Панель → Настройки → «Войти как стример» (под **своим** аккаунтом, не бота!)
3. На своём канале Twitch → Dashboard → Channel Points → создай награды
4. Панель → 👑 Награды канала → настрой мэппинги (название награды → что делает бот)

**Событие содержит:** кто купил (`user_login`), какой текст вставил (`user_input` — например YouTube-ссылку), название награды (`reward.title`).

## Оверлей

Страница **`http://localhost:8080/overlay`** (Browser Source в OBS, 1920×1080):
- Всплывающие алерты (фоллоу, саб, рейд, мем, колесо)
- Список последних событий (Event List) — правый верхний угол
- Надпись «сейчас играет» (с soprano музыкального плеера)
- TTS-озвучка (Web Speech API)
- Свои медиа и звуки: gif/видео/картинки и mp3/wav/ogg — папка `overlay-media/` или загрузка прямо из панели (📺 Оверлей → «📁 Файлы алертов», до 64 МБ)

Настройка: панель → 📺 Оверлей. На каждый тип события:
- **Текст** — что писать в плашке (переменные `{user}`, `{viewers}`, `{months}`, `{recipient}`)
- **Медиа** — gif/картинка/видео (mp4/webm/mov/m4v/ogv) вместо эмодзи: видео зациклится и уйдёт вместе с алертом
- **Звук** — mp3/wav/ogg/flac/m4a отдельным файлом
- **Громк%** (0–100) — одна громкость на звук алерта и на звук видео-медиа
- **Сек** — сколько висит плашка; **Вкл** — показать/скрыть событие; «Тест» — глянуть без стрима

Сообщения в чат (приветствия фолловерам, благодарности сабам и т.п.) настраиваются отдельно — вкладка «События». Алерты в OBS и текст в чат работают независимо и друг друга не заменяют.

## TTS

Web Speech API в оверлее — озвучивает текст каждого алерта. Голос/скорость/громкость в панели (📺 Оверлей → «🔊 Озвучка»). Работает в браузере OBS — для качества открой оверлей через «Пользовательский браузер»/Chrome.

Отключить на конкретной странице: `?tts=0`.

## OBS

Управление OBS из чата через **obs-websocket 5**:
- `!сцена <имя>` (мод+) — переключить сцену
- `!сцены` (мод+) — список сцен

Включение: Инструменты в OBS → «Настройки WebSocket-сервера» → включить сервер + аутентификацию + пароль. Панель → Настройки → «🎬 OBS» → вставить пароль → «Проверить связь».

Смена адреса/пароля применяется на ходу, без перезапуска бота.

## Модули

Обычный **.js-файл в папке `modules/`** — кидаешь файл, бот его подхватывает на лету. Упавший модуль не роняет бота. Это полноправные плагины: им доступны чат, весь Twitch Helix API, хранилище, HTTP-запросы, OBS, оверлей, таймеры и состояние бота.

Готовые примеры в папке `modules/`:
- **`example.js`** — мини-демо: команды, хуки, хранилище, lifecycle
- **`vip-activity.js`** — рабочий модуль + **полный справочник API в комментариях** (каждая функция с примером)

```js
export default {
  name: 'покормить',
  description: 'кормим гостей пельмешками',
  settings: { блюдо: 'пельмешки 🥟' },              // правится из панели
  async start(api) { api.log('модуль запущен'); }, // lifecycle: включение
  async stop(api) { api.store.save(); },            // lifecycle: остановка
  commands: {
    'факт': '{user}, котики мурчат 🐱',                        // строка — простой ответ
    'хорни': {                                                // объект — фан-команда
      mode: 'roll', rollMin: 0, rollMax: 100, cooldown: 5,
      response: '{user} хорни на {roll}% 🤔',
      ranges: [{ from: 90, to: 100, text: '{user} хорни на {roll}% — слишком хорни 🔥' }],
    },
    'профиль': async (session, args, api) => {                // async-функция — весь API
      const u = await api.helix.get('/users', { login: args[0] || session.login });
      await api.say(u?.data?.[0]?.display_name ?? 'не нашла');
    },
  },
  events: {
    'chat.message': async (m, api) => { /* каждое сообщение; return false = заблокировать! */ },
    'tick': async (_, api) => { /* раз в 20 секунд */ },
    'stream.online': async (ev, api) => { await api.announce('Мы в эфире!'); },
  },
};
```

### API модулей

Полный справочник каждой функции. `api` приходит во все хуки, команды-функции и `start`/`stop`.

#### Чат и сообщения

| Вызов | Что делает |
|---|---|
| `await api.say(текст, {channel})` | написать в чат (по умолчанию — канал события; `channel` — логин другого канала бота) |
| `await api.announce(текст, {color, channel})` | цветное объявление (цвет: blue/green/orange/purple/primary) |
| `await api.pin(текст, {channel})` | закрепить сообщение на 20 минут |
| `await api.shoutout(ник, {channel})` | настоящий шатаут Twitch (карточка + кнопка Follow) |

#### Twitch Helix API — прямой доступ

Любой эндпоинт [Helix](https://dev.twitch.tv/docs/api/reference/) токеном бота. Ошибки — обычные исключения (лови `try/catch` внутри модуля).

| Вызов | Что делает |
|---|---|
| `await api.helix.get(path, query)` | GET-запрос: чтение данных |
| `await api.helix.post(path, body)` | POST-запрос: создание (таймаут, бан, объявление…) |
| `await api.helix.del(path, query)` | DELETE-запрос: удаление (разбан, снятие VIP…) |

Примеры вызовов:

```js
const user = await api.helix.get('/users', { login: 'ник' });            // найти юзера
const stream = await api.helix.get('/streams', { user_login: 'канал' }); // инфо о стриме
const vips = await api.helix.get('/channels/vips', { broadcaster_id: id }); // список VIP
const mods = await api.helix.get('/moderation/moderators', { broadcaster_id: id }); // список модов
const chatters = await api.helix.get('/chat/chatters', { broadcaster_id: id, first: 100 }); // кто в чате
// таймаут на 10 минут спамеру:
await api.helix.post('/moderation/bans', { broadcaster_id: id, data: [{ user_id: uid, reason: 'спам', duration: 600 }] });
// снять VIP / разбанить:
await api.helix.del('/channels/vips', { broadcaster_id: id, user_id: uid });
await api.helix.del('/moderation/bans', { broadcaster_id: id, user_id: uid });
```

#### Helix токеном стримера (для наград)

`api.broadcaster.helix` — те же `get` / `post` / `del`, но токеном **стримера** (нужен «Вход как стример» в панели; Twitch отдаёт некоторые данные — например, награды канала — только владельцу канала). Если стример не залогинен, методы возвращают `{ error: 'стример не залогинен' }` вместо исключения.

```js
const rewards = await api.broadcaster.helix.get('/channel_points/custom_rewards', { broadcaster_id: id });
```

#### Хранилище (persist)

Персистентное key-value хранилище модуля — файл `data/module-store/<имя>.json`. Переживает рестарт бота. Запись отложенная (debounce 3 сек), при остановке модуля — принудительная. Ключи хранилища видны в панели (`storageKeys` в реестре модулей).

| Вызов | Что делает |
|---|---|
| `api.store.get(ключ, дефолт)` | прочитать значение (если нет — вернуть дефолт) |
| `api.store.set(ключ, значение)` | записать (автосохранение на диск) |
| `api.store.delete(ключ)` | удалить ключ |
| `api.store.all()` | копия всего хранилища |
| `api.store.save()` | принудительно записать на диск сейчас |

```js
api.store.set('visits', (api.store.get('visits', 0) || 0) + 1);
```

#### HTTP-запросы (fetch через прокси)

| Вызов | Что делает |
|---|---|
| `await api.fetch(url, opts?)` | внешний HTTP-запрос → `{ status, body }` (body — строка). Ходит через прокси, если тот включён в настройках бота. `opts`: `method` (GET/POST/…), `headers`, `body` (строка/Buffer/объект — объект сериализуется в JSON с Content-Type) |

```js
const joke = JSON.parse((await api.fetch('https://official-joke-api.appspot.com/random_joke')).body);
await api.say(`😂 ${joke.setup} — ${joke.punchline}`);
// POST с JSON-телом:
await api.fetch('https://example.com/api', { method: 'POST', body: { hello: 'мир' } });
```

#### OBS (сцены, источники)

Управление OBS (obs-websocket 5), как у команды `!сцена`. Если OBS не подключён — вместо данных придёт `{ error: 'OBS не подключён' }`.

| Вызов | Что делает |
|---|---|
| `await api.obs.setScene(имя)` | переключить текущую сцену → `true` \| `{error}` |
| `await api.obs.getScenes()` | список сцен → `{ scenes: [...], current: '...' }` |
| `await api.obs.toggleSource(сцена, источник, видим?)` | включить/выключить источник в сцене |

```js
await api.obs.setScene('BRB');
const scenes = await api.obs.getScenes();
await api.obs.toggleSource('Игровая', 'Webcam', false); // выключить вебку
```

#### Оверлей (push)

| Вызов | Что делает |
|---|---|
| `api.overlay.push(payload)` | кинуть событие в шину оверлея `/overlay` (SSE) |

```js
api.overlay.push({ kind: 'meme', text: '🎉 Событие!', sound: 'hype.mp3' });
api.overlay.push({ kind: 'wheel', text: '🎡 Кто-то крутил колесо' });
```

#### Таймеры (managed)

Обычные `setInterval`/`setTimeout` в модулях запрещены — только управляемые: бот чистит их сам при остановке/перезагрузке модуля.

| Вызов | Что делает |
|---|---|
| `api.setInterval(fn, мс)` | периодический таймер модуля |
| `api.setTimeout(fn, мс)` | одноразовый таймер модуля |

```js
api.setInterval(() => api.log('тик'), 60_000);        // раз в минуту
api.setTimeout(() => api.say('⏱ Время вышло!'), 10_000); // через 10 секунд
```

#### Данные и состояние

| Вызов / поле | Что делает |
|---|---|
| `api.state.counters` | счётчики бота (`messagesSeen`, `commandsRun`, `follow`, `raid`, `sub`…) |
| `api.state.running` | подключён ли бот к Twitch |
| `api.state.channels` | логины всех каналов бота |
| `api.channels()` | все каналы бота: `[{id, login, displayName}]` |
| `api.channel` | логин канала, где случилось событие (у хуков; иначе `null`) |
| `api.settings` | настройки модуля (объект, правится в панели) |
| `api.saveSettings()` | принудительно сохранить настройки |
| `api.log(текст, уровень?)` | строка в системную ленту панели (уровень: info/warn/error) |
| `api.stop()` | выключить сам модуль (после этого он «выкл» в панели) |

#### События (хуки)

| Хук | Когда | Payload |
|---|---|---|
| `'chat.message'` | каждое сообщение чата | объект сообщения EventSub (`chatter_user_id`, `message.text`…); **`return false` — заблокировать событие** |
| `'chat.notification'` | уведомление чата (саб/рейд внутри чата) | объект уведомления |
| `'follow'` | новый фоллоу | `user_name`, `user_login`… |
| `'raid'` | рейд | `user_name`, `viewers`… |
| `'sub'` | первая подписка | из chat.notification |
| `'resub'` | продление подписки | из chat.notification |
| `'subgift'` | подаренная подписка | из chat.notification |
| `'stream.online'` | стрим начался | `broadcaster_user_id`… |
| `'stream.offline'` | стрим закончился | `broadcaster_user_id`… |
| `'redemption'` | покупка награды канала (Channel Points) | `reward.title`, `user_input`… |
| `'tick'` | каждые 20 секунд, пока бот работает | `{ now }` |

**Перехват:** если хоть один хук `chat.message` вернул `false` — событие блокируется целиком: встроенная обработка (команды, автошатауты, таймеры, события) его не увидит.

#### Команды (строка / async-функция / объект)

| Форма | Как работает |
|---|---|
| `'факт': '{user}, котки 🐱'` | строка — шаблонный ответ (переменные как у кастомных команд) |
| `'профиль': async (session, args, api) => {}` | функция — полный доступ к API; `session` = `{broadcasterId, userId, login, displayName, level}`, `args` — слова после `!команды`. Метаданные: `fn.level = 'mod'`, `fn.cooldown = 30` |
| `'хорни': { mode: 'roll', ... }` | объект — фан-команда как из панели (mode: text/variants/roll, chance, cooldown, level, ranges…) |

#### Lifecycle

| Хук | Когда вызывается | Обязан сделать |
|---|---|---|
| `async start(api)` | загрузка бота, включение модуля в панели, перезагрузка файлов | инициализация, `api.setInterval`… |
| `async stop(api)` | выключение в панели, hot-reload, остановка бота | `api.store.save()`, закрыть свои соединения (managed-таймеры чистятся сами) |

Ошибка внутри `start()` бота не роняет: модуль помечается ошибкой (видно в панели), лог — в системной ленте. Правишь файл — бот сам перезагружает модуль, и `start()` пробует снова.

Кастомные команды из панели **сильнее** модульных (при конфликте имён побеждает панель). Встроенные команды (`!so`, `!сцена`…) тоже сильнее.

#### Пример готовых модулей

- **`modules/example.js`** — команды всех трёх типов, хук `chat.message`, хранилище-счётчик, `start`/`stop`.
- **`modules/vip-activity.js`** — авто-снятие VIP с неактивных (по умолчанию `dryRun: true` — только предупреждает в лог). Нужны скоупы `channel:read:vips` / `channel:manage:vips`: если бот входил до их появления, выйди и войди заново. В шапке файла — полный справочник API с примерами.

## Прокси

Если сервер бота не может дойти до YouTube за метаданными (название/длина трека):

Панель → Настройки → «🌐 Прокси»:
- Включи «ходить через прокси»
- Укажи http-прокси (например `http://127.0.0.1:8080`)
- «Проверить связь» — покажет, проходит ли запрос

Влияет только на **серверные** запросы к YouTube. Проигрывание в OBS идёт через браузер OBS.

## Обновление

В папке бота — `update.bat` (двойной клик). Или:

```powershell
powershell -ExecutionPolicy Bypass -File update.ps1
```

Git-установка: `git pull`. Данные (токены, настройки, цитаты, музыка, модули) не трогаются.

## FAQ

**Чем отличается от PhantomBot/Firebot?** Это ~50 КБ кода без зависимостей. Только нужные функции, чистый Node.js, официальные API Twitch.

**Бот молчит** — смотри ленту ⚙︎ на дашборде: там причины. Чаще всего: забыт `/mod` или вошли не под тем аккаунтом.

**Куда деваются токены?** `data/tokens.json` и `data/broadcaster-tokens.json` — хранятся только на твоём компе, никуда не отправляются.

**Можно ли на сервер?** Да, на любом VPS с Node.js 22+. Клонируй через git и запусти `node src/index.js`. Панель слушает только 127.0.0.1 — для удалённого доступа используй SSH-туннель.
