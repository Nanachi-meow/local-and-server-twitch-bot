### Кастомные и фан-команды

Создаются из панели (вкладка «Команды») или чатом (`!addcmd`). Режимы ответа:

- **один ответ** — фиксированный текст-шаблон
- **несколько вариантов** — список по строке, бот тянет случайный
- **рандом-число** — бросает число в диапазоне, отвечает по диапазонам (например: 1-10 = «почти не хорни», 90-99 = «срочно остудитесь», 100 = «слишком хорни»)

Переменные: `{user}` `{target}` `{args}` `{channel}` `{uptime}` `{game}` `{title}` `{random:1-100}` `{roll}`

## Каналы

До 10 каналов. Добавление/удаление на ходу из панели. В каждом канале, где нужны шатауты/анонсы/закрепы, бот должен быть модератором.

## События и шаблоны

На каждое Twitch-событие — свой шаблон и режим (текст или анонс):
- Новый фоллоу (`!followage` тоже здесь)
- Рейд (сколько зрителей)
- Саб / продление / продление / подаренная подписка
- Стрим онлайн / оффлайн

Переменные: `{user}` `{viewers}` `{months}` `{recipient}` `{channel}`

## Таймеры

Периодические сообщения по расписанию. У каждого: интервал (в минутах), условие («по времени» / «по сообщениям» / «и» / «или»), вкл/выкл.

Режимы: «по времени» (раз в N минут), «по сообщениям» (после N сообщений в чате), «и время, и сообщения» (оба условия), «или время, или сообщения» (любое из них).

## Музыка

Зрители заказывают треки через `!ср <ссылка YouTube>`. Бесплатные команды — оплата через **награды канала Twitch** (см. ниже) или просто так.

- Плеер: отдельная страница **`http://localhost:8080/music`** (Browser Source в OBS)
- Отдельная аудиодорожка: правый клик по источнику в микшере OBS → «Расширенные свойства аудио» → назначь дорожку, отличную от стрима
- Кастомизация: файл `src/public/sr-player.js` — правь как хочешь (контракт `init()` / `onEvent()` в шапке)
- Шаблон «сейчас играет»: панель → 🎵 Музыка → поле (переменные `{title}`, `{by}`, `{author}`, `{duration}`)
- Фильтры: макс. длительность, лимит треков на юзера, дубликаты

## Награды канала

Channel Points — встроенная валюта Twitch. Зрители покупают награды, бот видит событие и реагирует.

**Как включить:**
1. В dev.twitch.tv/console → твоё приложение → добавь ВТОРОЙ Redirect URL: `http://localhost:8080/auth/broadcaster/callback`
2. Панель → Настройки → «Войти как стример» (под **своим** аккаунтом, не бота!)
3. На своём канале Twitch → Dashboard → Channel Points → создай награды
4. Панель → 👑 Награды канала → настрой мэппинги (название награды → что делает бот)

**Событие содержит:** кто купил (`user_login`), какой текст вставил (`user_input` — например YouTube-ссылку), название награды (`reward.title`).

## Оверлей

Страница **`http://localhost:8080/overlay`** (Browser Source в OBS, 1920×1080):
- Всплывающие алерты (фоллоу, саб, рейд, мем, колесо)
- Список последних событий (Event List) — правый верхний угол
- Надпись «сейчас играет» (с soprano музыкального плеера)
- TTS-озвучка (Web Speech API)
- Свои звуки: кидай mp3/wav/ogg в папку `overlay-media/`

Настройка: панель → 📺 Оверлей (на каждый тип события: текст, звук, длительность, вкл/выкл).

## TTS

Web Speech API в оверлее — озвучивает текст каждого алерта. Голос/скорость/громкость в панели (📺 Оверлей → «🔊 Озвучка»). Работает в браузере OBS — для качества открой оверлей через «Пользовательский браузер»/Chrome.

Отключить на конкретной странице: `?tts=0`.

## OBS

Управление OBS из чата через **obs-websocket 5**:
- `!сцена <имя>` (мод+) — переключить сцену
- `!сцены` (мод+) — список сцен

Включение: Инструменты в OBS → «Настройки WebSocket-сервера» → включить сервер + аутентификацию + пароль. Панель → Настройки → «🎬 OBS» → вставить пароль → «Проверить связь».

Смена адреса/пароля применяется на ходу, без перезапуска бота.

## Модули

Обычный **.js-файл в папке `modules/`** — кидаешь файл, бот его подхватывает на лету. Упавший модуль не роняет бота.

```js
export default {
  name: 'покормить',
  description: 'кормим гостей пельмешками',
  settings: { блюдо: 'пельмешки 🥟' },
  commands: {
    'факт': '{user}, котики мурчат на 25–150 Гц 🐱',
    'хорни': {
      mode: 'roll', rollMin: 0, rollMax: 100, cooldown: 5,
      response: '{user} хорни на {roll}% 🤔',
      ranges: [{ from: 90, to: 100, text: '{user} хорни на {roll}% — слишком хорни 🔥' }],
    },
  },
  events: {
    'chat.message': async (m, api) => { /* каждое сообщение */ },
    'follow': async (ev, api) => { /* новый фоллоу */ },
    'sub': async (ev, api) => { /* подписка */ },
    'stream.online': async (ev, api) => { /* стрим начался */ },
    'redemption': async (ev, api) => { /* покупка награды канала */ },
    'tick': async (now, api) => { /* раз в 20 секунд */ },
  },
};
```

### API модулей

| Вызов | Что делает |
|---|---|
| `api.say(текст, {channel})` | написать в чат |
| `api.announce(текст, {color, channel})` | цветное объявление |
| `api.pin(текст, {channel})` | закрепить |
| `api.shoutout(ник, {channel})` | шатаут |
| `api.settings` | настройки модуля (объект) |
| `api.saveSettings()` | сохранить настройки |
| `api.channel` | канал события |
| `api.channels()` | все каналы бота |
| `api.log(текст)` | строка в системный лог панели |

События: `chat.message` · `chat.notification` · `follow` · `raid` · `sub` · `resub` · `subgift` · `stream.online` · `stream.offline` · `redemption` · `tick`

Кастомные команды из панели **сильнее** модульных (при конфликте имён побеждает панель).

## Прокси

Если сервер бота не может дойти до YouTube за метаданными (название/длина трека):

Панель → Настройки → «🌐 Прокси»:
- Включи «ходить через прокси»
- Укажи http-прокси (например `http://127.0.0.1:8080`)
- «Проверить связь» — покажет, проходит ли запрос

Влияет только на **серверные** запросы к YouTube. Проигрывание в OBS идёт через браузер OBS.

## Обновление

В папке бота — `update.bat` (двойной клик). Или:

```powershell
powershell -ExecutionPolicy Bypass -File update.ps1
```

Git-установка: `git pull`. Данные (токены, настройки, цитаты, музыка, модули) не трогаются.

## FAQ

**Чем отличается от PhantomBot/Firebot?** Это ~50 КБ кода без зависимостей. Только нужные функции, чистый Node.js, официальные API Twitch.

**Бот молчит** — смотри ленту ⚙︎ на дашборде: там причины. Чаще всего: забыт `/mod` или вошли не под тем аккаунтом.

**Куда деваются токены?** `data/tokens.json` и `data/broadcaster-tokens.json` — хранятся только на твоём компе, никуда не отправляются.

**Можно ли на сервер?** Да, на любом VPS с Node.js 22+. Клонируй через git и запусти `node src/index.js`. Панель слушает только 127.0.0.1 — для удалённого доступа используй SSH-туннель.
