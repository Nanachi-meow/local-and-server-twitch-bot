# 🧩 Шаблон редактора виджета — движок + конфиг

Здесь лежит **движок редактора раскладки** — вытащен 1:1 из редактора
виджета музыки (вкладка «Музыка» → «📐 Раскладка плеера»). Используется,
чтобы собирать новые редакторы виджетов быстро: смотрим, копируем, подключаем.

## Файлы

| Файл | Что это |
|---|---|
| `editor-engine.js.txt` | копия `src/public/editor-engine.js` — сам движок |
| `app-editor-config.js.txt` | пример: конфиг редактора рулетки (типы + подключение) |
| `index-editor.html.txt` | пример: HTML-блок секции редактора в панели |

## Что движок делает сам (НЕ копировать в новый виджет)

- сцена 1920×1080, k = width/1920, z-сортировка, прозрачность, грань
- выделение: клик / shift+клик / рамка «как на рабочем столе» / группа тащится монолитом
- магниты: центр И края к осям сцены (синий пунктир) и к соседям (оранжевый)
- история ctrl+z/y (снимок на каждый жест), буфер ctrl+c/x/v
- чипсы объектов, панель свойств (группа: прозрачность/слои/удаление)
- ресайз за уголок (правила — за типом), свои хэндлы-ручки у типов

## Как собрать новый редактор виджета

1. В панели: HTML-блок как `index-editor.html.txt` — тулбар + `#<id>-stage` + `.chips #<id>-objects` + `#<id>-props`.
2. В app.js — конфиг как `app-editor-config.js.txt`:
   - нормализация настроек → массив объектов `{id,type,x,y,w,h,opacity,z,...}`;
   - `EditorEngine.create({ stage, chips, props, objects, k, onChange, hotkeyGate, types })`;
   - на каждый тип объекта: `render` (внутренности div), `props`+`bind` (поля свойств),
     `resize` (как растягивается), `handles` (свои ручки: стрелки и т.п.), `copyable: false`
     для объектов «один на виджет».
3. Сохранение: `onChange` синкает объекты → в настройки виджета; кнопка 💾 шлёт PUT /api/settings.
4. Сервер: в белый список настроек добавляются поля объектов (клампы!).
5. Оверлей: рендерит объекты по тем же формулам, что `render` в редакторе.

## Типы-примеры (из рулетки)

- `wheel` — круглый объект + стрелка с двумя ручками (орбита и ↻-поворот) + свои слайдеры;
  `copyable: false`, кастомный `resize` (круг).
- `text` — окно текста: ширина ресайзом, высота по содержимому, шрифт/цвет/прозрачность;
  `copyable: false`.
- `image` — картинка-декор: заливка из /media, грань, углы, загрузка, копируется.
