# 🤖 Локальный Twitch-бот с веб-панелью

Полностью свой, полностью локальный бот для твич-чата. Никаких подписок, никаких облаков и чужих серверов — всё крутится на твоём компе, токены хранятся только у тебя. Панель настроек открывается в браузере.

Написан с нуля на чистом Node.js **без единой зависимости** (не нужен даже `npm install`) и только на **официальных публичных API Twitch** (Chat Bot API + EventSub WebSocket). IRC не используется — это уже legacy, Twitch официально рекомендует новый путь.

## Что умеет

- 💬 **Мониторит чат** — живая лента в панели, с меткой канала
- 🧩 **Кастомные команды** — с правами доступа, кулдаунами, счётчиком вызовов; редактируются из панели или прямо из чата (`!addcmd`). Режимы ответа: один текст, несколько случайных вариантов или **рандом-число с диапазонами** («хорни на 37% — срочно остудитесь»), плюс условие «нужен @ник», шанс срабатывания и гибкая студия на вкладке 🎭 Фан
- 📺 **Несколько каналов** — до 10 каналов на одного бота; добавление и удаление на ходу, без перезапуска
- 📣 **Шатауты** — настоящий шатаут Twitch (`!so <ник>`): всплывающая карточка + кнопка Follow
- 📌 **Закрепы** — `!pin <текст>` закрепляет сообщение в чате (официальный API Pin Chat Message), `!unpin` снимает
- 📢 **Анонсы** — цветные системные объявления (`!announce [цвет] <текст>` и кнопки в панели)
- 💜 **Реакции на события** — новый фоллоу, рейд, саб, продление саба, подаренная подписка: свои шаблоны, режим (текст/анонс), автозакреп
- ⏱ Полезное: `!uptime`, `!game`, `!title`, `!followage`, `!commands`
- 📣 **Автошатауты** — друзья-стримеры пишут любое сообщение → бот сам кидает шатаут с их кастомным текстом
- 📌 **Автозакреп** — на старте стрима бот сам отправляет приветственное сообщение и закрепляет его («до конца стрима» или на 20 минут)
- ⏰ **Периодические сообщения (таймеры)** — бот сам напоминает про соцсети, дискорд и правила по расписанию: у каждого сообщения свой интервал, «только когда стрим в эфире», вкл/выкл любого таймера — как тикеры в WizeBot
- 👑 **Награды канала Twitch (Channel Points)** — второй вход «как стример» (забирает списания наград: Twitch отдаёт их только токену владельца канала), бот пишет каждое списание в ленту событий и показывает замапленные награды в оверлее. Плюс бесплатные фан-команды: **колесо** (`!колесо`), **мем-алерты** (`!мем название`) и **говорилка** (`!сказать текст` — TTS-озвучка)
- 📺 **Оверлей для OBS** — локальная страница-оверлей: всплывающие алерты событий и купленные мемы, список последних событий (Event List) в углу, свои звуки, настройка из панели
- 🎬 **Управление OBS** — смена сцены прямо из чата (`!сцена <имя>`, `!сцены`), связь по obs-websocket 5, всё локально

<a id="install"></a>
## 🚀 Установка — все способы

Понадобится: **Node.js 22+** (ставится один раз) и **отдельный аккаунт Twitch для бота** — заведите его заранее на twitch.tv (НЕ личный и не стримерский: так правильно и так делают все).

**Node.js:** открой **https://nodejs.org** → кнопка **LTS** → скачай и установи (галочки по умолчанию). Проверка: `Win+R` → набери `cmd` → Enter → в чёрном окошке `node -v` → должно показать `v22` или новее. (Linux/macOS: `brew install node` / `apt install nodejs` или с сайта.)

Выбери любой способ — результат одинаковый:

### 🥇 Способ 1 — установщик двойным кликом (Windows, самый простой)

1. 👉 **[скачать install.bat](https://github.com/Nanachi-meow/local-and-server-twitch-bot/releases/latest/download/install.bat)** — если кнопка не работает: [страница релизов](https://github.com/Nanachi-meow/local-and-server-twitch-bot/releases) → блок **Assets** → `install.bat` → Download.
2. Двойной клик по скачанному файлу.
3. Windows спросит «разрешить внесение изменений?» — **Разрешить** (это обычный текстовый скрипт, можно открыть блокнотом и посмотреть, что внутри).
4. Откроется окошко выбора папки — выбери, куда поставить бота (или создай новую) → **ОК**.
5. Скрипт сам скачает и распакует. Спросит «Запустить бота сейчас?» → набери **`y`** (или Enter = «потом», тогда запускай `start-bot.bat` из папки бота).

### 🖥 Способ 2 — через PowerShell (хочешь указать путь руками)

Скачай [`install.ps1`](https://github.com/Nanachi-meow/local-and-server-twitch-bot/releases/latest/download/install.ps1), положи куда удобно и запусти:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -Path "C:\twitch-bot"
```

### 📦 Способ 3 — просто zip-архив (без скриптов)

1. 👉 **[скачать zip бота](https://github.com/Nanachi-meow/local-and-server-twitch-bot/archive/refs/heads/main.zip)**
2. Правый клик по архиву → **«Извлечь всё…»** → выбери папку.
3. Зайди в появившуюся папку → двойной клик **`start-bot.bat`**.

### 🐧 Способ 4 — для Linux/macOS и гиков (git)

```txt
git clone https://github.com/Nanachi-meow/local-and-server-twitch-bot.git
cd local-and-server-twitch-bot
node src/index.js
```

Бот запущен правильно, когда в браузере открылась панель **http://localhost:8080** (она видна только с твоего компьютера). Дальше — 🔌 [первый запуск](#first-run).

<a id="first-run"></a>
## 🔌 Первый запуск: подключаем Twitch (~5 минут, один раз)

### 1. Создай «приложение» в Twitch

Twitch пускает ботов в чат только через официальное «приложение»:

1. Зайди на **https://dev.twitch.tv/console/apps/create** (логин — под **твоим личным/стримерским** аккаунтом, НЕ бота).
2. **Name** — любое, например `moj-lokalny-bot`.
3. **OAuth Redirect URL** — добавь **два** адреса: `http://localhost:8080/auth/callback` (вход бота) и `http://localhost:8080/auth/broadcaster/callback` (вход стримера — нужен для наград канала; оба подсвечены на дашборде бота — кликни, чтобы скопировать).
4. **Category** — выбери `Chat Bot`.
5. Жми **Create**.
6. Скопируй **Client ID** (виден сразу) → рядом **New Secret** → скопируй **Client Secret**.

Запиши оба значения — понадобятся прямо сейчас.

### 2. Заполни панель бота

1. Панель → вкладка **«Настройки»**.
2. Вставь **Client ID** и **Client Secret** → **«Сохранить»**.
3. Ниже в «Каналы, где работает бот» впиши имя **СВОЕГО канала** (где ты стримишь) → **«Добавить канал»**. Аккаунт бота туда писать **не надо**.

### 3. Войди как БОТ (не как ты!) — самая частая ошибка

Бот должен авторизоваться под **своим отдельным аккаунтом**. Если в браузере залогинен твой личный — токен привяжется к тебе, и ничего не заработает. Поэтому:

1. Открой **инкогнито-окно** (в Chrome/Яндекс: `Ctrl+Shift+N`).
2. В нём зайди на twitch.tv и залогинься **под аккаунтом бота**.
3. В панели бота (обычное окно): «Настройки» → **«Войти как бот»**.
4. Twitch спросит «Разрешить доступ?» → **Authorize** (важно: в инкогнито должен быть залогинен именно бот).

Панель покажет: «Вход выполнен: ник_бота».

### 4. Дай боту права модератора в своём чате

Зайди на свою страницу Twitch → свой чат → напиши ровно:

```txt
/mod ник_бота
```

Без этого не работают шатауты, анонсы, закрепы, фоллоу-приветствия и часть алертов — Twitch требует прав модератора.

### 5. (опционально) Войди как стример — награды канала

Чтобы бот видел списания наград канала (Channel Points), нужен второй вход — уже под **твоим** аккаунтом: «Настройки» → карточка **«👑 Награды канала»** → **«Войти как стример»**. Twitch спросит разрешение — разреши. Это опционально: без входа бот просто не получает события наград.

### Готово 🎉

На дашборде горит «✅ чат подключен (6/6 подписок)». Со входом стримера подписок станет 7 (+ «награды @канал»). Можно стримить!

<a id="help"></a>
## ❓ Если что-то не заводится

- Панель не открывается → запущен ли бот? (`start-bot.bat` в папке бота.) В браузере адрес ровно `http://localhost:8080`.
- «Бот не авторизован» → шаг 3 точно делали под аккаунтом бота (инкогнито)? Если сомневаешься: «Настройки» → «Выйти (сбросить токен)» → снова «Войти как бот».
- «Канал не найден» → имя канала без `@` и без опечаток.
- Шатауты/анонсы/алерты «нет прав» → сделан ли шаг 4 (`/mod ник_бота`)?
- Награды канала не приходят → «Войти как стример» сделан? аккаунт стримера — владелец канала из списка? В приложении на dev.twitch.tv добавлен Redirect URL `http://localhost:8080/auth/broadcaster/callback`?
- Windows не даёт запустить .bat (SmartScreen) → «Подробнее» → «Выполнить в любом случае»: скрипты открываются блокнотом, зла в них нет.

<a id="custom"></a>
## 🎭 Кастомные и фан-команды

Два места с одной и той же базой:

- Вкладка **«Команды»** — полный список: быстрая правка текстов, доступа и кулдаунов.
- Вкладка **«🎭 Фан»** — студия фан-команд: создание по шагам и раскрытые меню настроек у каждой команды. Есть готовые шаблоны в один клик (обнять, хорни с диапазонами, шар, совместимость).

### Как устроена фан-команда

1. **Имя** и **условие активации**: «🎯 нужен @ник» — без `@ник` бот ответит подсказкой «укажи ник»; без галочки команда работает и так, а `{target}` без аргумента подставит самого вызвавшего.
2. **Режим ответа** (меняется в меню команды в любой момент):
   - **💬 один ответ** — фиксированный текст-шаблон;
   - **🎲 несколько вариантов** — список по строке, бот выбирает случайный;
   - **#️⃣ рандом-число** — бот бросает число в заданном диапазоне («от»/«до») и отвечает текстом по диапазонам: например, `0–10` → «вы почти не хорни 😌», `40–60` → «очень хорни 😳», `90–99` → «срочно остудитесь 🧊», `100` → «вы слишком хорни 🔥». Для чисел вне диапазонов используется текст-заглушка.
3. **Шанс %** — вероятность ответа вообще (0 — молчит всегда, 100 — всегда); кулдаун списывается даже при «мимо». Плюс доступ (все/сабы/VIP/моды), кулдаун и тумблер вкл. Все команды бесплатные: цена, если нужна, живёт в награде канала Twitch (см. «👑 Награды канала»).

Переменные: `{user}` — кто вызвал, `{target}` — цель (`@ник` или сам вызвавший), `{args}`, `{channel}`, `{uptime}`, `{game}`, `{title}`, `{random:1-100}`, а в рандом-числе — `{roll}` (выпавшее число).

Пример для «хорни» (готовый шаблон): диапазон 0–100, диапазоны ответов:
`0–10: {user} хорни на {roll}% — вы почти не хорни 😌` … `100: {user} хорни на 100% — вы слишком хорни 🔥`.

В чате по-прежнему работают `!addcmd !имя ответ`, `!editcmd`, `!delcmd` (мод+) — так создаются простые текстовые команды.

<a id="events"></a>
## События и шаблоны

Вкладка «События»: на каждый тип события свой шаблон и режим.

- **Текст бота** — обычное сообщение от бота; можно сразу «закрепить на 20 минут» (закреп заменяет предыдущий).
- **Анонс** — цветное системное объявление (красиво, но закрепить анонс нельзя — Twitch не возвращает id анонса).

Переменные: `{user}`, `{channel}` (в какой канал пришло), `{viewers}` (рейд), `{months}` (продление саба), `{recipient}` (кому подарок). Кнопка «Тест» прогоняет событие с подставными данными прямо в чат.

По умолчанию:
- фоллоу: `💜 {user} зафолловил(а) канал — добро пожаловать в семью!`
- рейд: `🚀 РЕЙД от {user}! {viewers} зрителей с нами — располагайтесь ❤️`
- саб: `🎉 {user} оформил(а) подписку! Спасибо за поддержку!`
- продление: `💜 {user} продлил(а) подписку — уже {months} мес. с нами!`
- подарок: `🎁 {user} дарит подписку → {recipient}! Щедрость уровня бог!`

<a id="channels"></a>
## Несколько каналов и смена на ходу

Список «Каналы, где работает бот» — в «Настройках». Добавление и удаление **применяются сразу**, без перезапуска: бот молча переподключается (пару секунд «чат отключен», потом снова зелёное).

- До 10 каналов на бота.
- В каждом канале, где нужны **шатауты, анонсы, закрепы, фоллоу-приветствия и слежение за фоллоу**, бот должен быть **модератором** — `/mod имя_бота` в том канале. Где прав нет — там работают обычные команды и чтение чата, а модераторские фишки панель пометит ошибкой подписки.
- В логе панели у каждого сообщения и события стоит метка канала (`#имя`).
- В «Быстрых действиях» есть селектор: в какой канал писать анонс/закреп/шатаут.
- Если в список случайно попал **аккаунт самого бота** — панель покажет предупреждение, а бот будет слушать «свой» чат. Убери его оттуда: там должно быть имя твоего (или чужого) канала.

<a id="rewards"></a>
## 👑 Награды канала Twitch (Channel Points)

Бот не заводит собственные баллы: используются **настоящие награды канала Twitch** — зрители тратят их в чате, Twitch сам списывает очки. Чтобы бот видел эти списания и мог на них реагировать, нужен второй вход:

1. **«Настройки» → карточка «👑 Награды канала» → «Войти как стример»** — войти под **своим** стримерским аккаунтом (не бота!). Twitch отдаёт события списания наград (`channel.channel_points_custom_reward_redemption.add`) только токену **владельца канала** — токену бота-модератора они недоступны.
2. В приложении на dev.twitch.tv должен быть добавлен Redirect URL `http://localhost:8080/auth/broadcaster/callback` (см. первый запуск).
3. Токен стримера хранится в `data/broadcaster-tokens.json` и обновляется автоматически, как у бота.

Что бот делает со списанием награды сейчас:

- **лента событий** — каждое списание пишется на дашборде (кто, какая награда, что ввёл);
- **оверлей** — награды из таблицы мэппингов всплывают алертом `👑 kind: redemption` (с озвучкой TTS, как у других алертов); кулдаун на зрителя (по умолчанию 30 сек) защищает от спама;
- **таблица мэппингов** — «Настройки» → 👑: название награды на Twitch + действие (песня/мем/колесо/TTS/команда) + вкл/выкл. Сейчас действие справочное: автоматическая привязка награды к заказу песни или мему появится следующей фазой. Пока — лог + красивый алерт в оверлее.

Пока привязки нет, команды-аналоги работают бесплатно: `!ср` (заказ музыки), `!мем название`, `!колесо`, `!сказать текст` — баллы не списываются, цена при желании ставится в самой награде на Twitch.

Ещё по настройкам: список мэппингов и кулдаун лежат в `data/settings.json` (`redemptions`), тест-кнопка «Тест: алерт в оверлее» показывает алерт не стримя.

<a id="songs"></a>
## 🎵 Плеер музыки для OBS (заказы музыки)

Зрители заказывают треки командой `!ср <ссылка YouTube>` — бесплатно (цена заказа, если нужна, ставится в награде канала Twitch; автоматическая привязка — в планах). Очередь в `data/songs.json`, всё локально.

| Команда | Доступ | Что делает |
|---|---|---|
| `!ср <ссылка>` | все | заказ песни (дубликаты/длина/лимит на юзера фильтруются) |
| `!ср` / `!очередь` | все | что играет / очередь |
| `!скип` | мод+ | пропустить трек |
| `!музыка пауза \| прод \| стоп` | мод+ | управление |
| `!song <ссылка>` | все | псевдоним `!ср` |

### Отдельная аудиодорожка (авторские права)

Плеер живёт на своей странице **`http://localhost:8080/music`** — добавь её в OBS как **отдельный Браузер-источник** (ш/вырол любой). Теперь зайди в **микшер OBS → правый клик по источнику «music» → «Расширенные свойства аудио»** и поставь галочки на дорожку, ОТЛИЧНУЮ от стрим-микса (например только «Дорожка 2» в записи) — музыка в стрим не попадёт, а твоей записи неслышно не будет.

### Кастомизация плеера

- Шаблон «сейчас играет»: панель → «🎵 Музыка» → поле (переменные `{title}`, `{by}`, `{author}`, `{duration}`).
- **Плеер заменяемый целиком**: файл `src/public/sr-player.js` — правь как хочешь (позиция надписи, анимация, что угодно), оверлей вызовет только `init()`/`onEvent()` (контракт в шапке файла). Надпись «сейчас играет» есть и на главном `/overlay` — это одна строчка `render()`, меняй тоже.
- Звук на главном `/overlay` не играет — он отвечает за алерты, музыка — на `/music`.

### Прокси

Если сервер бота (не OBS) не может дойти до YouTube за названиями треков: «Настройки» → «🌐 Прокси» — включи и укажи http-прокси (например `http://127.0.0.1:8080`), кнопка «Проверить связь» показывает, проходит ли запрос.

### Как это работает под капотом

- Плеер `/music` слушает ту же SSE-шину, что и оверлей (`/overlay/feed`, события `kind:'sr'`): `play`/`stop`/`pause`/`resume`/`update`.
- Когда ролик закончился — плеер сам постит `POST /api/songs {op:'ended'}` — сервер двигает очередь и рассылает следующий трек.
- Метаданные (название/длина) — через YouTube oEmbed + разбор страницы (без API-ключей); если не удалось — заказ отклоняется.

## Цитаты

Таблица лучших высказываний чата с автоматической нумерацией: номера не переиспользуются, даже если цитату удалили. Хранение — `data/quotes.json`.

| Команда | Доступ | Что делает |
|---|---|---|
| `!цитата` | все | случайная цитата в формате «Цитата #12: …» |
| `!цитата N` | все | цитата по номеру (нет такой — бот честно скажет) |

| `!цитата добавить <текст>` | мод+ | сохранить цитату (до 300 символов), бот отвечает номером |
| `!цитата удалить N` | мод+ | удалить цитату по номеру |

Панель со списком и удалением — карточка **«📖 Цитаты»** на вкладке «Команды»: список с номерами, добавление (автором помечается «Панель») и удаление кнопкой; список обновляется после каждого действия. Цитаты по-прежнему доступны и из чата.

<a id="modules"></a>
## Модули (пишем свои)

Всё, чего нет «из коробки», можно добавить модулем — это обычный **.js-файл в папке `modules/`**. Никаких сборщиков и зависимостей: скопировал файл — он работает. Правки подхватываются **на лету** (бот следит за папкой; есть и кнопка «Перезагрузить» в панели). Упавший или кривой модуль **не роняет бота** — он просто помечается ошибкой во вкладке «🧩 Модули».

Готовый образец лежит в `modules/example.js` — открой и перепиши под себя.

```js
export default {
  name: 'покормить',                    // как звать в панели (необязательно)
  description: 'кормим гостей пельмешками',

  // настройки: дефолты задаёшь ты, менять можно в панели (вкладка «🧩 Модули»)
  settings: {
    блюдо: 'пельмешки 🥟',
  },

  // команды: строка = простой ответ; объект = любая схема фан-команды
  commands: {
    'факт': '{user}, котики мурчат на 25–150 Гц 🐱',
    'хорни': {
      mode: 'roll', rollMin: 0, rollMax: 100, cooldown: 5,
      response: '{user} хорни на {roll}% 🤔',
      ranges: [{ from: 90, to: 100, text: '{user} хорни на {roll}% — слишком хорни 🔥' }],
    },
  },

  // хуки на события: async (событие, api) => { ... }
  events: {
    'chat.message': async (m, api) => { /* каждое сообщение чата */ },
    'follow': async (ev, api) => { /* новый фоллоу */ },
    'sub': async (ev, api) => { /* подписка */ },
    'stream.online': async (ev, api) => { /* стрим начался */ },
    'redemption': async (ev, api) => { /* списание награды канала: ev.reward.title, ev.user_login, ev.user_input */ },
  },
};
```

### События (ключи хуков)

`chat.message` · `chat.notification` · `follow` · `raid` · `sub` · `resub` · `subgift` · `stream.online` · `stream.offline` · `redemption` (награда канала) · `tick` (раз в 20 секунд)

Поля событий — как у Twitch: у сообщения это `m.broadcaster_user_id`, `m.chatter_user_name`, `m.message.text` и т.д.

### API для модулей

| Вызов | Что делает |
|---|---|
| `api.say(текст, {channel})` | написать в чат (по умолчанию — канал события) |
| `api.announce(текст, {color, channel})` | цветное объявление |
| `api.pin(текст, {channel})` | закрепить сообщение |
| `api.shoutout(ник, {channel})` | настоящий шатаут |
| `api.settings` | настройки модуля (объект; панель умеет их править) |
| `api.saveSettings()` | сохранить настройки в `data/modules.json` |
| `api.channel` | канал, в котором случилось событие |
| `api.channels()` | все каналы бота (логины) |
| `api.log(текст)` | строка в системный лог панели |

Важно: в командах-строках работают те же переменные, что и в фан-командах: `{user}`, `{target}`, `{args}`, `{channel}`, `{uptime}`, `{game}`, `{title}`, `{random:1-100}`, `{roll}`. Кастомные команды (из панели) сильнее модульных — при совпадении имён побеждает панельная.

<a id="overlay"></a>
## Оверлей и медиа-алерты (для OBS)

Аналог media-alerts больших облаков, только всё локально:

1. Скачай звуки (mp3/wav/ogg) и кидай их в папку **`overlay-media/`** проекта — они появятся в списке у каждого события.
2. Панель → вкладка **«📺 Оверлей»**: текст каждого алерта (переменные `{user}`, `{viewers}`, `{months}`, `{recipient}`, `{channel}`), звук, длительность, вкл/выкл; **«Тест»** показывает алерт не дожидаясь события.
3. В OBS: «Источники» → **+** → **Браузер** → URL `http://localhost:8080/overlay`, размер 1920×1080, фон прозрачный.
4. Фоллоу, сабы, продления, подарки и рейды всплывают с анимацией и звуком поверх стрима.
5. **📋 Список событий (Event List)** — лента последних событий в правом верхнем углу оверлея (эмодзи + строка мелким шрифтом, старые строки затухают). Включается галочкой «список событий в углу оверлея» во вкладке «📺 Оверлей» (настройка `alerts.eventList`: `enabled`, `size` — сколько строк, 1–20); на конкретной странице — параметром `?events=1`. Питается тем же SSE-потоком, что и алерты, — второе соединение не открывается.
6. **🔊 TTS-озвучка** (Web Speech API, локально): во вкладке «📺 Оверлей» включи «Озвучка (TTS)», выбери скорость (0.5–2), громкость (0–1) и голос из списка браузера (русские — первыми; «Проверить голос» произносит тестовую фразу без сервера). Оверлей озвучивает текст каждого показанного алерта (фоллоу/саб/…/мем/колесо/награда канала), фразы читаются по очереди, не перебивая друг друга; имя голоса искомо в оверлее по названию, при отсутствии — берётся первый русский. Чтобы временно выключить озвучку на странице (сцена/отладка), добавь к адресу `?tts=0`. Важно: голоса зависят от браузера, где открыт оверлей, — для максимального качества открой оверлей в OBS через «Пользовательский браузер»/Chrome, а не старый CEF, если синтез речи там недоступен.

<a id="obs"></a>
## OBS-интеграция (obs-websocket 5)

Бот управляет OBS по официальному протоколу obs-websocket 5 — как Streamer.bot, только без облаков и зависимостей: используется встроенный WebSocket Node 22, пароль обрабатывается через challenge/salt + SHA-256 (`node:crypto`).

Что доступно прямо сейчас:

- `!сцена <имя>` (мод+) — переключить текущую сцену; если такой сцены нет, бот перечислит доступные;
- `!сцены` (мод+) — список сцен и какая из них активна;
- модулям и будущим фичам — методы клиента: смена сцены, тумблеры источников (вкл/выкл любого источника в сцене).

### Как включить (у пользователя)

1. В самом OBS: **Инструменты → Настройки WebSocket-сервера**:
   - включи **WebSocket-сервер** (в свежих OBS обычно уже включён);
   - включи **аутентификацию** и задай **пароль**;
   - порт по умолчанию — **4455** (можно сменить, тогда укажи новый в панели).
2. Панель → вкладка **«Настройки»** → карточка **«🎬 OBS»**: хост (почти всегда `127.0.0.1`), порт, пароль, галочка «интеграция включена» → **«Сохранить»**.
3. **«Проверить связь»** подключается к OBS и показывает список сцен — сразу видно, что адрес и пароль верные (работает и до сохранения).
4. Готово: пиши в чат `!сцены` и `!сцена БРБ`.

Нюансы:

- Пароль хранится локально в `data/settings.json` (как Client Secret) и никуда не отправляется, кроме твоего OBS.
- Если OBS выключен, бот молча переподключается сам (пауза растёт от 5 до 60 секунд); команды честно отвечают «OBS не подключён».
- Пока OBS подключён, бот пингует его раз в 25 секунд (протокольный `GetVersion`) — зависшее соединение заметит и пересоздаст.
- Смена хоста/порта/пароля или вкл/выкл в панели применяется **на ходу**, без перезапуска бота.

<a id="security"></a>
## Данные и безопасность

- Сервер слушает **только 127.0.0.1** — снаружи панель не доступна, не пробрасывай порт.
- Токены бота: `data/tokens.json` (обновляются автоматически). Никому не показывай.
- Токен стримера (для наград канала): `data/broadcaster-tokens.json` (тоже обновляется автоматически). Тоже секрет.
- Client Secret: в `config.json`. Тоже секрет.
- Все настройки: `config.json` + `data/settings.json` + `data/commands.json` — обычный JSON, можно править руками при остановленном боте.
- Бот читает и пишет только в твой канал, только от имени твоего же бота-аккаунта.

## Автозапуск вместе с Windows

Создай файл `start-bot.bat` в `shell:startup` (Win+R → `shell:startup`):


## Ограничения (честно)

- **Закреп через `!pin` — 20 минут**: так работает официальный эндпоинт `Send Chat Message` с `pin:true`. Из панели можно закрепить и на 10–30 минут (там используется другой эндпоинт).
- **Шатаут** — Twitch разрешает раз в 2 минуты, одного и того же человека — раз в час. Это лимит Твича, не мой.
- **Обычный (неверифицированный) бот** пишет максимум ~20 сообщений в 30 секунд (бот-модер — 100/30с). Бот сам держит паузу 1.5 сек между сообщениями.
- **Фоллоу-ивенты** видит только в каналах, где бот модератор (Twitch требует скоуп модератора для `channel.follow`).
- **Награды канала** видны только после «Входа как стример» — Twitch отдаёт списания наград только токену владельца канала. Подписка создаётся для каналов, принадлежащих залогиненному стримеру.
- Один бот — до 10 каналов (это наш лимит, лимитов Twitch для обычного аккаунта хватает с запасом). Больше — заведи второго бота с другим портом (`$env:BOT_PORT='8081'; node src/index.js`).
- Вхи́сперы ботам недоступны без верификации бота в Twitch — их тут и нет.

## Автошатауты

Вкладка «Автошатауты». Список ников; каждый может иметь свой текст (пусто — общий дефолтный). Как только человек из списка пишет **любое** сообщение в любом канале, где работает бот:

1. Бот кидает настоящий шатаут Twitch (карточка с кнопкой Follow) —
2. И пишет строку с текстом. Переменные: `{target}`, `{target_login}`, `{channel}`.

Кулдаун — настраивается, по умолчанию 240 минут (4 часа) на человека. Это нужно из-за лимитов Twitch: карточка шатаута не чаще 1 раза в 2 минуты на канал и не чаще 1 раза в час одному и тому же человеку. Если карточка «не влезла» в лимит, бот всё равно напишет строку и отметит причину в логе. Кнопка «Тест» у каждого человека проверяет связку, игнорируя кулдаун (но не лимиты Twitch).

## Автозакреп

Вкладка «События», карточка «Автозакреп на старте стрима». Когда EventSub сообщает, что стрим начался, бот сам:

1. Отправляет сообщение (твой шаблон, доступна переменная `{channel}`),
2. И закрепляет его в чате.

Два режима: **«до конца стрима»** (официальный режим закрепа Twitch — снимется сам по окончании стрима) и **«на 20 минут»**. Если бот перезапустили прямо во время стрима, он проверит: закрепа нет — обновит; чужой закреп на месте — не тронет. Требует модератора, разумеется.

<a id="timers"></a>
## Таймеры (периодические сообщения)

Вкладка «Таймеры». Бот сам пишет заготовленные сообщения через свои интервалы — чтобы зрители не забывали про соцсети, дискорд и правила, пока ты играешь.

- **Список таймеров** — до 30 штук; у каждого: название (для себя), текст, интервал в минутах (1–720), порог сообщений (1–1000), режим, тумблер вкл/выкл.
- **Режимы срабатывания**:
  - **по времени** — раз в N минут (классика);
  - **по сообщениям** — после N сообщений в чате канала (чтобы таймеры не выстреливали в мёртвый чат);
  - **и время, и сообщения** — оба условия одновременно: интервал прошёл И с прошлого выхода накопилось N сообщений;
  - **или время, или сообщения** — любое из условий: сработает, что наступит раньше.
- Счётчик сообщений — на каждый канал отдельно, обнуляется после каждого выхода таймера; сообщения самого бота не считаются.
- **«Писать только когда стрим в эфире»** — по умолчанию включено: в оффлайн-чат ничего не уходит (можно снять галку — тогда пишет всегда).
- **Тумблер «таймеры включены»** — глобальный выключатель на случай «завязываем с автоматикой».
- **Мультиканальность** — сообщение уходит во все каналы бота, где сейчас идёт эфир.
- **Тест-кнопка** у каждого таймера — отправить его прямо сейчас в канал, выбранный в «Быстрых действиях», не дожидаясь интервала.
- После запуска бота или добавления таймера первый выход — через полный интервал (без мгновенного спама).

Переменные в тексте: `{channel}`, `{uptime}` (сколько идёт стрим), `{game}`, `{title}`, `{random:1-100}`.

<a id="faq"></a>
## Частые вопросы

**Хочу сменить аккаунт бота** — «Настройки» → «Выйти», залогинься в Twitch под нужным аккаунтом (инкогнито помогает), снова «Войти как бот».

**Бот молчит, в панели «чат отключен»** — смотри ленту ⚙︎ на дашборде: там пишутся причины (нет настроек, нет входа, канал не найден). Чаще всего: забыт `/mod` или в шаге 3 вошли не под тем аккаунтом.

**Чем это отличается от PhantomBot/Firebot?** Те — классные тяжёлые комбайны (Java и Electron). Этот бот — ~40 КБ кода без зависимостей, только нужные функции, панель на чистом HTML/JS, и он изначально построен на новом официальном Chat Bot API (EventSub), а не на легаси-IRC.
