# ROADMAP — Twitch-бот: фичи больших ботов, чистой комнатой

Идея: перенести полезное из Streamer.bot / Mix It Up / StreamElements / JeetBot
в наш локальный бот с нуля. Никакого копирования кода/ассетов — только поведение,
описанное публично. Всё на чистом Node.js, без зависимостей.

Статусы: [ ] не начато · [~] в работе · [x] готово.

уведомление с текстом и звуком. Всё локально.

## Фаза 6 — Channel Points (кастомные награды) [блокировано]

❌ По исследованию (docs/research/streamerbot-mixitup.md): событие `channel.channel_points_custom_reward_redemption.add` и `bits:read` требуют скоупы, которые Twitch выдаёт только токену бродкастера, а у нас вход под аккаунтом бота-модератора. Разблокируется, только если добавить второй вход под стримерским аккаунтом (отдельная фича «двойная авторизация»). Альтернатива уже есть: redemption-магазин на СВОИХ баллах (см. волна 2, Redemption Store).

## Волна 2 — бэклог из исследований (полные разборы: docs/research/*.md)

Приоритет от исследований Streamer.bot/MixItUp/StreamElements/JeetBot; оценки — под наш стек (Node + оверлей + наши баллы):

1. [ ] **OBS-клиент** (obs-websocket 5, чистый WebSocket из Node 22): смена сцены/тумблеры по командам и событиям — фаза 8
2. [ ] **Redemption Store** — магазин «услуг» на своих баллах: запас (quantity), ручное подтверждение стримером, типы (клип/код/текст/TTS)
3. [ ] **Требования команд** — цена в баллах за любую команду, персональные/групповые кулдауны, анти-спам ошибок
4. [ ] **`!сказать <текст>` за баллы** — TTS с ценой и фильтром мата (движок TTS уже есть)
5. [ ] **Heist** — групповой набег на баллы (каждый со своим исходом)
6. [ ] **Ранги** по баллам/watch-time + переменная `{ранг}` в шаблонах
7. [ ] **Статистика юзеров**: watch time, last seen, счётчики + входные приветствия по юзеру
8. [ ] **Гивэвей** (вход → таймер → победитель → `!claim`) и **Game Queue** (очередь поиграть со стримером)
9. [ ] **Оверлей-виджеты**: Event List, Follow Goal, Leaderboard, Stream Boss (баллы=урон), титры — поверх готового SSE
10. [ ] **Вариации алертов** — тир子/месяцы саба/размер рейда → разные тексты/медиа (gif/video) + персональные кулдауны
11. [ ] **Правила событий** (jeetbot-style): событие + условия + цепочка действий + симулятор
12. [ ] **BRB-экран** `!brb N`, «топы сессии» со сбросом после оффлайна, kappagen-лайт (полёт эмодзи)
13. [ ] **Миграция баллов/цитат на user_id** — смена ника не теряет ничего (критик + исследование)
14. [ ] **Автомодерация** — слова по границам, капс/эмодзи/ссылки, страйки→таймаут (нужны доп. мод-скоупы → перевход бота)

## Правила выживания (для любой новой сессии)

1. Прочитать этот файл и `README.md` → продолжать с первой незакрытой фазы.
2. Коммит на каждый шаг: `git add -A && git commit -m "фаза N: ..."`.
3. После правок: `npm run selftest` (обязательны все тесты) и перезапуск бота
   скрыто: `Start-Process node -ArgumentList 'src\index.js' -WorkingDirectory 'Z:\Проекты\twitch-bot' -WindowStyle Hidden`
   (НЕ через start-bot.bat — он открывает окно и браузер).
4. Миграции настроек — только добавляющие поля, старые файлы не ломать.
5. Никаких зависимостей: чистый Node 22+, никаких npm install.
