# ROADMAP — Twitch-бот: фичи больших ботов, чистой комнатой

Идея: перенести полезное из Streamer.bot / Mix It Up / StreamElements / JeetBot
в наш локальный бот с нуля. Никакого копирования кода/ассетов — только поведение,
описанное публично. Всё на чистом Node.js, без зависимостей.

Статусы: [ ] не начато · [~] в работе · [x] готово.

## Правила выживания (для любой новой сессии)

1. Прочитать этот файл и `README.md` → продолжать с первой незакрытой фазы.
2. Коммит на каждый шаг: `git add -A && git commit -m "фаза N: ..."`.
3. После правок: `npm run selftest` (обязательны все тесты) и перезапуск бота
   скрыто: `Start-Process node -ArgumentList 'src\index.js' -WorkingDirectory 'Z:\Проекты\twitch-bot' -WindowStyle Hidden`
   (НЕ через start-bot.bat — он открывает окно и браузер).
4. Миграции настроек — только добавляющие поля, старые файлы не ломать.
5. Никаких зависимостей: чистый Node 22+, никаких npm install.
